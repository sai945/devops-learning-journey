# 01 - Introduction to Linux

## Overview

This lesson introduces Linux, its distributions, the Linux shell
and basic commands used to interact with a Linux system.

## Learning Objectives

- Understand what Linux is.
- Understand Linux distributions.
- Learn how the shell works.
- Understand the Linux terminal prompt.
- Execute basic Linux commands.
- Navigate directories.
- Create directories and files.
- Redirect command output into files.

## Topics Covered

1. What is Linux?
2. Linux Distributions
3. Understanding the Shell
4. Your First Commands
5. pwd, ls and cat
6. mkdir and cd
7. Redirecting Output with >


## Key Takeaway

Linux is a fundamental operating system in modern DevOps
environments. Understanding basic Linux commands is essential
for managing cloud servers, containers and applications.
